# Rate90 0.2 赛前页面开发说明

本文描述开发分支 `feature/0.2-prematch-sol` 的赛前页面。下面的交互示例使用 2026 年 11 月 23 日的快照。

## 页面行为

| 入口 | 当前行为 |
| --- | --- |
| 单项赛事 → 轮次 | 同一个下拉框可选历史轮次和未来两个整轮。赛程载入后显示实际轮名，如英超「第 12 轮」「第 13 轮」。左右箭头可跨历史和未来轮次切换。 |
| 全部赛事 → 轮次 | 「即将开赛」「后续赛程」分别取各赛事未来第一个、第二个整轮，按赛事分组。一个整轮要求该轮所有比赛都还未开球。 |
| 日期 | 按北京时间选未来日期，显示当天尚未开球的对阵，包括已开始轮次中的剩余比赛。历史日期继续展开对应整轮，休赛日回到此前最近比赛日。 |
| 未来对阵 | 展示主客队、队徽、开球日期和时间。开球时间未知时显示「待定」。窄屏把主客队分成两行。 |
| AI 赛前推荐 | 后端返回的推荐与当前整轮或日期的比赛 ID 集合吻合时，展示首选、次选及理由。推荐为空时只展示赛程。 |

## 代码入口

| 文件 | 职责 |
| --- | --- |
| [app.js](../public/ui/app.js) | 读取和写入联赛、轮次、日期路由，载入赛前快照，处理日历和浏览器前进、后退。 |
| [views.js](../public/ui/views.js) | 生成轮次下拉框、左右箭头和标题，决定展示历史比赛还是未来对阵。 |
| [upcoming.js](../public/ui/upcoming.js) | 按赛事或北京时间选出对阵，匹配推荐，渲染赛程列表和推荐卡。 |
| [site.css](../public/ui/site.css) | 赛事标题、首选和次选卡、赛程行及移动端布局。 |
| [verify-ui.mjs](../scripts/verify-ui.mjs) | 页面交互回归，含轮次切换、跨赛事、日历、返回导航及历史详情。 |

页面从 [collected-index.js](../public/ui/data/collected-index.js) 的 `prematchFile` 找到对应的赛前快照。`rounds` 提供整轮，`extra` 补充按日查看的比赛，`picks` 按轮次或按日期保存推荐。示例快照有 6 项赛事、12 个整轮、132 场整轮对阵，另有 3 场按日补充，推荐为 0 条。

## 本地复核

在开发分支根目录运行 `npm start`，打开本地服务。下表的轮次与场数以北京时间 2026-11-23 17:00 为准，交互测试已固定该时点，便于快照滚动后复现。

| 操作 | 示例快照的预期结果 |
| --- | --- |
| 打开 `http://127.0.0.1:3000/?league=pl&round=next` | 英超第 12 轮，10 场对阵。 |
| 点右箭头，再切换到「全部赛事」 | 先显示英超第 13 轮，再显示 6 项赛事各自的第二个未来整轮，共 66 场。 |
| 在日历选 11 月 25 日，然后用浏览器后退 | 列表仅显示北京时间 11 月 25 日的对阵。后退恢复此前的轮次选择。 |

该版本的 `npm test` 通过 55 项，`npm run test:ui` 通过 6 项（jsdom 26.1.0）。首次运行交互测试可执行 `npm install --no-save --package-lock=false jsdom@26`。移动端可用长队名和两条赛前推荐检查列表换行及推荐卡排版。
