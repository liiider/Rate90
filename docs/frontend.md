# Rate90 前端

`public/index.html` 是本地文件和静态托管的共同入口。首页按赛事展示各自最近有比赛完赛的一轮。选择「全部轮次」可看完整赛程。日期和开球时间按北京时间展示。

| 入口 | 操作 |
| --- | --- |
| 赛事与轮次 | 在全部赛事或单项赛事中选择轮次，选「全部轮次」恢复该范围下的所有轮次 |
| 日期跳转 | 展开当前赛事范围内所选日期涉及的每一轮，包含该轮跨日比赛。休赛日取此前最近的比赛日 |
| 比赛详情 | 直接查看首发、替补、教练和阵型。「比赛数据」「比赛动态」「战术分析」分别点击偷看，每次只解锁本场的一个标签 |
| 战术分析 | 切换主队或客队，按时间查看该队的首发部署、临场调整及 AI 点评 |
| 中文 / English | 在右上角切换界面、球队和阵容的显示语言，刷新后保留选择 |

列表用图标表示推荐理由，打开详情可读标签名称与具体看点。轮内按评分排序。

## 推荐理由

| 理由 | 依据 |
| --- | --- |
| 强强对话 | 双方上赛季均进入欧冠八强或五大联赛前二 |
| 宿敌相逢 | 两队是已收录的传统对手，如曼彻斯特德比、米兰德比 |
| 关键先生 | 同一人两次参与扳平或取得领先，或多次参与进攻且包含第 80 分钟后的关键一球。第 85 分钟后打入最后制胜球也计入 |
| 问题人物 | 同一球员既有进攻贡献，又有被罚下、乌龙或罚失点球的记录，或有两次这类失误 |
| 争议判决 | 有可核查的独立裁判评议认定关键判罚有误。目前收录英超第 4 轮的曼彻斯特德比和桑德兰对阿森纳。[英超评议](https://www.premierleague.com/en/news/4725955) |
| 判罚焦点 | 事件记录有涉及进球、点球、红牌的实质性 VAR 复核，已标争议判决的场次不重复展示 |
| 疯狂对攻 | 至少 24 次射门，双方各有至少 4 次关键机会，至少两个 15 分钟窗口双方都有威胁 |
| 流畅配合 | 一次运动战进攻有至少四脚可核实的传球并包含最后一传，四人参与，或三人参与且有回做 |
| 门将高光 | 常规时间出现至少三次高难度扑救 |
| 尾声悬念 | 末段至少 12 分钟平局或一球差，最后 15 分钟至少有三次关键机会 |

## 数据与日期

| 文件 | 作用 |
| --- | --- |
| `public/ui/data/fixtures.js`、`teams.js` | 基础赛程、球队名称和队徽，比赛评分来自 Rate90 快照 |
| `public/ui/data/process-ratings.js`、`rounds/` | 本轮公开快照，索引携带评分、推荐理由与比赛日文件位置 |
| `public/ui/data/collected-index.js`、`collected/` | 持续采集发布的更新 |
| `public/ui/catalog.js` | 按比赛 ID 与赛程别名合并来源，打开详情时读取对应比赛日的文件 |

例如曼城对富勒姆的 BSD ID 为 `209642`。北京时间 11 月 21 日 20:30 开球，日期跳转到英超第 11 轮时可见。API 的看球日以中午分界，对应 `date=2026-11-22`。源数据重建和动态采集均沿用此 ID。

`public/matchweek.html` 保留比赛周旧入口。`public/world-cup-2022.html` 是独立的世界杯历史资料页，提供三场的常规时间分段射门与 xG。
